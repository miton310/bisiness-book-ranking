# おすすめ診断機能

## 概要
ユーザーがチェックボックスで「悩み・目的」を選択し、それに合った本をおすすめする機能。

## UI案

```
あなたに合った本を見つけよう！

□ 自己成長・人生を変えたい
□ 仕事で成功したい
□ お金・投資を学びたい
□ 健康・習慣を改善したい
□ 教養を深めたい
□ テクノロジーを学びたい

[おすすめを見る]
```

## カテゴリマッピング

| チェック項目 | 対応カテゴリ |
|------------|-------------|
| 自己成長・人生を変えたい | 人文・思想 |
| 仕事で成功したい | ビジネス・経済 |
| お金・投資を学びたい | 投資・金融・会社経営 |
| 健康・習慣を改善したい | 暮らし・健康・子育て |
| 教養を深めたい | ノンフィクション、社会・政治 |
| テクノロジーを学びたい | 科学・テクノロジー、コンピュータ・IT |
